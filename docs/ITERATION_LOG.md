## R7 改动与 S3 时的判断

本轮实现的直接执行变化是外层分块规划：从四个固定候选扩为按维度、对齐和核数生成候选，考虑 K、布局相关访存代理、轮数和调用成本；Matmul UB 预算由硬件容量约束，SDK 最多尝试前 4 个候选及 32×64 回退。设备计算主体、两次全核屏障和最后的顺序补偿求和保持 R5 路径。

配套工程改变是统一 C++ 候选来源、记录 SDK 接受的真实配置和内部基本块、自动生成用例、按同一输入身份关联采样。工具本身不产生设备提速，启发式权重也不是校准后的延迟模型。实现细节见 [Matmul 规划](MATMUL_TILING.md)。

最新反馈的收益集中于第 8–12 点：其中第 9、10、11、12 点分别快 2.25、3.72、3.36、7.14 倍。这些点的 shape 未知，只能称为对应点号的观测，不能直接标成“大矩阵”。

需要继续处理的现象：

- 第 1–4 点仍约 12–14 μs，变化为 +0.55%～+5.63%；第 5 点增至 17.44 μs。通用通信/同步固定成本是待检验解释，当前无分阶段计时证明。

## R8：小规模快路径实现

代码版本：`2663797`，开发基线 `b6f6a0c`（计算版本 `1cc3cba`）。公开 `run_kernel` ABI、原有 GM 设备计算及 `matmul_plan.h` 保持不变；线上每次调用仍恰好启动一个 kernel。

核心变化：

- 新增 AIV-only `SmallVectorKernel`。先把 FP16/BF16 转成 FP32，再按 K 连续 Dot 或 N 连续 Rows 计算，核内 Max 与顺序补偿 Sum，直接输出 y。
- 命中时跳过 Matmul tiler、通信 workspace、完整 similarity/row-max GM scratch 和跨核屏障。每个核独占连续 8 个输出所在的 32B 组，尾组只写有效字节。
- 合法范围为 B≤32、M≤16、N≤64、K≤256 且 K%8=0、MNK≤32768；Rows 另要求 MK≤64。Dot 布局为 `(!TA || M==1) && (TB || N==1)`；其余仅 TB=false 可走 Rows。自动启用进一步要求任务组一轮完成、Dot 的 `min(B,8)*M*N≤16` 或 Rows 的 `min(B,8)*M*K≤32`。不满足条件就走原有 MIX。
- 对齐后的输入队列、FP32 输入和临时缓冲逐项计入 UB，占用为 `6*(aElements+bElements)+1344`，限制在 `min(64KiB, UB-32KiB)`。这些是保守实验阈值，未测量过快慢分界。
- 本地 runner 增加实际执行族的 schema 3 记录，兼容旧 GM 报告；small 明确不提供 similarity，仍检查 y。强制路径要求新元数据匹配，避免旧二进制被误认成测试了 small。原 tile sweep 固定 GM，未新增 family 性能矩阵。

验证记录：主机测试覆盖真实辅助代码的地址/布局/资源/数值逻辑、单次启动/无 scratch 分派、schema 3 序列化与旧报告兼容；另核对 GM 设备计算和公开入口与基线逐字一致。`python3 -m unittest discover -s tests -v`：58 项通过（72.194 秒），另通过 shell 语法和 diff 空白检查。CPU 替身是同步逻辑模型，不能证明真实指令、异步流水或 CANN 编译通过。

独立审查发现并修复了本地强制 family 未绑定实际请求的缺口；未发现确定的线上计算错误。开发机无 CANN/NPU，按用户新决策不安排额外本地 NPU 测试，也不以测出收益作为默认启用前置条件。提交前状态为 **LOCAL_CANN_BUILD=NOT_RUN，LOCAL_NPU_TEST=NOT_RUN，ONLINE_EVALUATION=NOT_RUN**；现已收到下方 S4 线上 15/15 Pass。线上通过说明用户提交版本完成了平台编译和测试，但源码版本仅按对话关联，不扩展为全部快路径分支已覆盖。

观察与归因：

- 点 1 下降 8.57 μs（69.22%），明显区别于其余点的变化，支持“减少通用 MIX 流程能解决一部分小规模开销”的方向。很可能命中了 small，但没有实际执行计划，不能认定是 Dot/Rows 中哪支，也不能反推精确 shape。3.81 μs 仍为最优的 3.12 倍，本次没有触及已知性能下限的证据。
- 数值上 12 点变快、3 点变慢，但除点 1 外，降幅最大为点 3 的 6.40%；变慢的点 8/12/13 仅为 0.73%/0.35%/0.04%。单轮不能把这些波动全部归为收益或稳定退化，也不能证明其余 14 点都未命中 small。
